# 척척학사 🎓

대학 생활의 학업 일정과 계획을 관리하는 멋쟁이사자처럼 13기 미니 해커톤 프로젝트입니다.

## 주요 기능

- **계정 관리:** 회원가입, 로그인, 프로필 수정
- **학업 관리:** 학점 및 졸업 관련 정보 확인
- **플래너:** 계획 작성과 상세 내용 조회
- **마이페이지:** 개인 정보와 학업 관련 화면

## 기술 스택

- **Frontend:** React, JavaScript, Create React App
- **Styling:** styled-components
- **Routing:** React Router
- **API:** Axios

## 실행 방법

```bash
npm install
npm start
```

프로덕션 빌드:

```bash
npm run build
```

일부 기능은 별도의 백엔드 서버 연결이 필요합니다.
